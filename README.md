# КП-5: Взаємодія фронтенду та бекенду (AJAX, обмін даними JSON)

**Дисципліна:** Сучасні технології розробки WEB-застосувань мовою програмування PHP  
**Варіант:** 11 - Система обліку студентів та оцінок  
**Виконав:** Сардаковський Денис Олександрович, група ІК-44 (ФІОТ КПІ)

## Структура проєкту

- `database.sql` - одноразовий SQL-скрипт створення БД `practicum5`, таблиці `students` (`id`, `name`, `group_name`, `average_grade`) та 6 початкових записів (`utf8mb4`).
- `db.php` - налаштування підключення до MySQL через PDO (`ERRMODE_EXCEPTION`, `FETCH_ASSOC`) із JSON-відповіддю при помилці з'єднання.
- `api_list.php` - JSON-ендпоінт (`GET`) для отримання всіх студентів або живої фільтрації за групою (`group_name`) через параметр `?q=...`.
- `api_add.php` - JSON-ендпоінт (`POST`) для валідації та додавання нового студента через підготовлений запит `INSERT` із відповіддю `201 Created`.
- `api_update.php` - JSON-ендпоінт (`POST`) для оновлення середнього балу (`average_grade`) студента за `id` через підготовлений запит `UPDATE`.
- `index.html` - клієнтська сторінка без PHP-виводу таблиці: форма додавання, поле живого пошуку та контейнер `#results`.
- `script.js` - асинхронна логіка на базі `fetch()` (`async/await`): початкове завантаження списку, живий пошук (`input`), додавання запису, миттєве редагування середнього балу в клітинці рядка та обробка помилок мережі/сервера.
- `style.css` - оформлення карток, форми, поля пошуку, таблиці та елементів inline-редагування.

## Локальний запуск

**Вимоги:** PHP 8.x із увімкненим розширенням `pdo_mysql`, сервер MySQL 8.x / MariaDB.

1. Клонувати репозиторій та перейти в папку проєкту:

```bash
git clone https://github.com/Denys0908/php_kp5.git
cd php_kp5
```

2. Створити базу даних `practicum5` і таблицю `students` за допомогою `database.sql` (через phpMyAdmin, HeidiSQL або консольний клієнт `mysql`):

```bash
mysql -u root --default-character-set=utf8mb4 < database.sql
```

> **Увага:** скрипт `database.sql` призначений для одноразової ініціалізації — він містить `DROP TABLE IF EXISTS students`, тому повторний запуск видалить внесені зміни й поверне 6 стартових записів.

3. За потреби перевірити параметри підключення (`$dbHost`, `$dbPort`, `$dbName`, `$dbUser`, `$dbPass`) у файлі `db.php`.

4. Запустити вбудований вебсервер PHP:

```bash
php -S localhost:8000
```

5. Відкрити у браузері адресу: `http://localhost:8000`
